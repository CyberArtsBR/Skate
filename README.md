# Chimpions Half-Pipe

Phase 1 foundation for a Three.js half-pipe skateboarding game. This checkpoint loads the visual half-pipe, the source skateboard, and one rigged Chimpion while deliberately leaving gameplay physics, tricks, scoring, and timer logic for later phases.

## Commands

```sh
npm install
npm run dev
npm run check
npm run build
```

Press `D` in the preview to toggle the independent half-pipe profile reference.
